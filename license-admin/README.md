# 授权码管理站

仿照 Django 后台（`/admin/`）样式实现的授权码签发站点。授权码随机生成，首次被设备使用时自动绑定，之后其它设备无法复用。

## 功能

- 管理员登录（会话 Cookie，12 小时过期）
- 直接生成授权码：可一次生成 1–500 个，格式 `XXXX-XXXX-XXXX-XXXX`（去掉了 I/O/0/1 等易混字符）
- **自定义有效期**：生成时填「有效期(天)」，从生成时刻起算；留空或 0 表示永久有效。
  到期后该码不能再绑定，已绑定的设备也会被判定未授权
- **生成后自动打包成 Excel 并下载**：文件名形如 `授权码-客户A-20261126-0207.xlsx`，
  只包含本次生成的那批码，可直接转发给客户；结果区也保留「下载本批 Excel」按钮
- 自动写出 `授权码.xlsx`：生成、解绑、删除时都会重写，工作表名为「授权码」，列为
  `授权码 / 备注 / 绑定设备 / 绑定时间 / 到期时间 / 生成时间 / 状态`
- 绑定管理：查看每个码绑定的设备与时间；「解绑授权码」输入框可直接粘贴任意授权码解绑，
  列表里每一行也有解绑按钮。解绑后该码可以绑定到另一台手机，备注与生成时间保留
- 导出：`下载表格`（xlsx）与 `导出 CSV`，导出的是全部授权码
- 客户端接口：`POST /api/v1/bind` 首次绑定、`GET /api/v1/status` 查询绑定状态

按客户发码时，在「备注」里填客户名称即可区分批次，不需要拆成多个表格。

## 运行

```bash
# 首次运行会随机生成管理员密码并打印在控制台
./license-admin

# 指定密码、端口，并把表格直接写到中控程序目录
LICENSE_ADMIN_PASSWORD=你的密码 ./license-admin \
  -addr 0.0.0.0:8090 \
  -xlsx "C:/Users/Administrator/Desktop/iOS群控Go版/授权码.xlsx"
```

打开 `http://<服务器地址>:8090/admin/`，用户名固定为 `admin`。

### 命令行参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `-addr` | `127.0.0.1:8090` | 监听地址；对外监听必须同时设置 `LICENSE_API_TOKEN`，否则拒绝启动 |
| `-data` | `records.json` | 授权码数据文件 |
| `-xlsx` | `授权码.xlsx` | 输出表格路径，建议指向中控程序所在目录 |
| `-key` | `signing.key` | 绑定签名私钥，首次启动自动生成 |

### 环境变量

| 变量 | 说明 |
| --- | --- |
| `LICENSE_ADMIN_PASSWORD` | 管理员密码；未设置时每次启动随机生成并打印 |
| `LICENSE_API_TOKEN` | 客户端调用 `/api/v1/*` 必须携带 `X-License-Token`。对外监听时必填 |

## 绑定签名

后台用 Ed25519 私钥为每个「授权码 + 手机 UDID + 到期时间」签名，中控只内置对应公钥：

- `/api/v1/bind` 与 `/api/v1/status` 的响应都带 `signature` 与 `expiresAt`
- 中控把它们存进 `授权备份.json`，断网时验签通过、且未过期才放行
- 手工改备份、伪造授权码、伪造服务器响应、篡改到期时间都会因验签失败被拒

到期时间采用统一的 RFC3339(UTC) 形式，签名、`/api/v1/bind`、`/api/v1/status` 三处一致，
否则客户端重建的待验签字符串会对不上。

公钥可通过 `GET /api/v1/pubkey` 查看，启动日志也会打印。**更换 `signing.key` 后必须同步更新 `license_client.go` 里的 `licensePublicKeyHex` 并重新编译客户端**，否则所有已授权设备都会失效。

## 防滥用

- 管理员登录：同一 IP 连续 5 次失败锁定 15 分钟
- 绑定接口：同一 IP 每分钟最多 30 次
- 对外监听强制要求 API 令牌，避免有人把未售出的码全部绑到垃圾设备上

## 与中控的配合

**一个授权码对应一台手机。**

1. 后台生成授权码 → `授权码.xlsx` 落到中控程序目录
2. 中控启动，读取表格，对每台已连接的手机发起首次绑定 `POST /api/v1/bind`
3. 后台记录「授权码 → 该手机 UDID」并返回结果；中控把这层关系写入本地 `授权备份.json`
4. 之后每次启动，中控用 `GET /api/v1/status` 把表格里的码与后台绑定结果比对：
   有绑定这台手机的码就放行，否则显示遮罩并禁止操作
5. 连不上后台时，中控改用本地备份校验：备份里的码**必须仍在表格中**才放行

解绑后该码可以绑定到另一台手机；删除后该码从中控表格消失，即使客户端离线也会被拦下。

## 安全说明

1. **不要把本站与客户端一起分发**，它掌握着发码能力。
2. 对外部署时务必设置 `LICENSE_ADMIN_PASSWORD`，并建议加一层 HTTPS 反向代理；
   默认只监听 `127.0.0.1`，对外暴露需显式 `-addr 0.0.0.0:8090`。
3. 中控在「连不上后台」时改用本地备份校验（备份里的码仍须在表格中）。这是产品选择：
   已授权用户断网不受影响，但管理员删码后离线也会失效。若希望断网一律禁止，改
   `license_client.go` 里 `refreshLicense` 的离线分支即可。
